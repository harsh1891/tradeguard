# TradeGuard

TradeGuard is a real-time market surveillance simulator for detecting suspicious order-flow behavior such as spoofing, wash trading, quote stuffing, fake liquidity walls, and abnormal cancellation rates.

The current version is an MVP: a synthetic exchange simulator emits order, trade, cancellation, and order book events; a rule-based detection engine scores suspicious activity; FastAPI exposes REST and WebSocket streams; and a React dashboard displays live market activity.

## Architecture

```text
Synthetic Traders
      |
      v
Python Matching Engine
      |
      v
Market Events -> Detection Engine -> Alerts
      |
      v
FastAPI REST + WebSockets
      |
      v
React Surveillance Dashboard
```

## Detection Coverage

- Spoofing: large orders cancelled quickly before execution.
- Fake liquidity walls: oversized visible orders away from the mid price.
- Wash trading: same or linked accounts trading with each other.
- Quote stuffing: excessive order traffic in a short time window.
- Abnormal cancellation: high cancel ratio over a minimum activity threshold.

## Run Locally

Backend:

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Open the dashboard at:

```text
http://127.0.0.1:8000
```

Then click **Start** to begin the live simulation.

The old React/Vite dashboard in `frontend/` is kept for future expansion, but the backend now includes a no-install dashboard at `/dashboard`, so you do not need `npm` to use the project.

## Deployment

TradeGuard is ready to deploy on Render. The included `render.yaml` installs backend dependencies and starts the FastAPI app.

## Benchmarking

TradeGuard includes an offline benchmark runner for measuring high-volume event processing without waiting for the real-time dashboard.

Run 100,000 market events:

```bash
cd backend
.venv\Scripts\python.exe scripts\benchmark.py --events 100000 --mode stream
```

Run 1,000,000 market events and save a JSON report:

```bash
cd backend
.venv\Scripts\python.exe scripts\benchmark.py --events 1000000 --mode stream --json-out benchmark_1m.json
```

Run the full exchange matching-engine path on a smaller sample:

```bash
cd backend
.venv\Scripts\python.exe scripts\benchmark.py --events 10000 --mode exchange
```

Use `stream` mode for large labelled datasets and `exchange` mode when you want to validate the order book and matching engine path.

The report includes:

- Events processed.
- Orders, trades, and cancellations.
- Alerts generated by type.
- Events processed per second.
- Average and max detection latency.
- Labelled precision against known synthetic manipulative traders.

Example resume wording after running the benchmark:

